## 1. 로그인 페이지

### 📋 기본 정보
- **경로**: `/login`
- **접근 권한**: 인증 필요 없음 (비로그인 사용자)
- **목적**: 사용자 인증 (GitLab OAuth)

### 🎨 UI 요소
```
┌─────────────────────────────────────┐
│                                     │
│         Graphify 로고               │
│                                     │
│    "기업 지식베이스 플랫폼"         │
│                                     │
│   ┌──────────────────────────────┐  │
│   │  GitLab으로 로그인           │  │
│   │  (버튼)                      │  │
│   └──────────────────────────────┘  │
│                                     │
│   또는                              │
│                                     │
│   ┌──────────────────────────────┐  │
│   │ 이메일:    [____________]    │  │
│   │ 비밀번호:  [____________]    │  │
│   │                              │  │
│   │      [ 로그인 ]              │  │
│   └──────────────────────────────┘  │
│                                     │
│ 처음이신가요? 가입하기              │
│                                     │
└─────────────────────────────────────┘
```

### 🔄 사용자 흐름
```
1. 사용자가 /login 접속
2. "GitLab으로 로그인" 버튼 클릭
3. GitLab OAuth 페이지로 리다이렉트
4. 권한 동의 후 콜백
5. JWT 토큰 발급 (localStorage)
6. /dashboard로 자동 리다이렉트
```

### 📡 API 호출
```
POST /api/auth/oauth/gitlab/callback
  Parameters: code, state
  Response: { token, user: { id, name, role } }
```

### 💾 상태 관리
- `AuthContext`: 로그인 상태, 사용자 정보, 토큰

## 3. 그래프 시각화

│ │ ☑ Function            ││                           │
│ │ ☑ Class              ││                           │
│ │ ☑ Module             ││  ◯ ─ ◯                  │
│ │ ☑ Concept            ││    ╱  ╲                  │
│ │                        ││   ◯   ◯  (vis.js)       │
│ │ 신뢰도:                ││    ╲  ╱                  │
│ │ ○ EXTRACTED만         ││    ◯ ─ ◯                  │
│ │ ◉ 모두 포함            ││                           │
│ │                        ││                           │

│                           │                           │

│ │                        │ │                           │
│ │ 노드: Function.login   │ │                           │
│ │ 타입: Function         │ │                           │
│ │ 파일: auth.py:42       │ │                           │
│ │ 커뮤니티: 인증         │ │                           │
│ │                        │ │                           │

│ │ ← Session.create (0.88)│ │                           │
│ │                        │ │                           │

│ └────────────────────────┘ │                           │
│                            │                           │
└─────────────────────────────────────────────────────────┘
```

### 🔄 사용자 흐름
```
1. /graph/:graphId 접속
2. 그래프 데이터 로드 (nodes, edges)
3. vis.js로 시각화
4. 노드 클릭 → 우측 패널에 상세 정보 표시
5. 필터 변경 → 그래프 동적 업데이트
6. 우측 패널에서 "상세보기" 클릭 → /graph/:graphId/node/:nodeId로 이동
```

### 📡 API 호출
```
GET /api/graphs/:graphId
  Response: { id, name, nodeCount, edgeCount, communities: [...] }

GET /api/graphs/:graphId/nodes
  Response: [{ id, label, type, community, source_file }]

GET /api/graphs/:graphId/edges
  Response: [{ source, target, relation, confidence }]

GET /api/graphs/:graphId/communities
  Response: [{ id, name, members: [...], godNodes: [...] }]
```

### 💾 상태 관리
- `GraphContext`: 그래프 데이터, 필터 상태, 선택된 노드
- `useQuery`: 그래프 데이터 페칭

## 7. 권한 설정

### 🎨 UI 요소
```
